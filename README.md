# RentOk Rent Collection Check

A small Node.js utility that reconciles rent charges against tenant payments. It flags unpaid charges, partial payments, and overpayments so property operations teams can review collection exceptions quickly.

Built as a focused RentOk application project for rent collection, tenant operations, and production reconciliation workflows.

## Run tests

```bash
npm test
```

## Scope

- deterministic rent-charge reconciliation;
- unpaid, partial, and overpaid charge reporting;
- concise operations summary for collection review.
